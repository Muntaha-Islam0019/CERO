# CERO

A text-only card game in a single Python file, made as a practice project for the students in my basics-of-Python classes at BRAC University Computer Club. It only uses what the [Hello-World](https://github.com/Muntaha-Islam0019/Hello-World) lessons cover: lists, loops, conditionals, functions and `random`.

## How it plays

- The deck has 55 cards: 1 to 10 in five colors (black, cyan, red, orange, indigo), plus five special cards named Uno, Dos, Tres, Cuatro and Cinco. CERO is Spanish for zero.
- Enter the number of players and a number of cards above 20, then each player spins the "Wheel of luck".
- Three or more colors showing even numbers score 2 points. Uno scores 1, Dos scores 2, and so on up to Cinco.
- Most points wins. A tie is settled by a toss.

## Play

```
python Happy_Coding_v1.py
```

Type `play` (or `?p`) to start, or `help` (or `?h`) for the rules.
